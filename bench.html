APEX 26 — FRAME COST BENCH

Runs the real game in an iframe on this machine and attributes the frame time. Nothing is uploaded.
idle
Every phase is measured on this same machine, back to back, with the render scale pinned and the performance governor switched off — otherwise the governor reacts to each phase and you measure its reaction instead of the cost. BASELINE is the shipped configuration; each row after it turns exactly one thing off. A large drop in median frame time when a subsystem is disabled is that subsystem's cost.

The car is DRIVEN for the whole run, by the same closed-loop autopilot the test suite uses — a braking envelope over a look-ahead scan, then pure pursuit back to the centreline — starting from the grid every time so two runs compare. The driving column is each row's alibi: a phase measured while the car sat still is not a measurement of a race, whatever its median says. The Δ column refuses to quote a number for a row that shed nothing — a knob already at zero, a write the tuner clamped, or a pass that never ran in this condition at all (lamp shadows by day). Those would otherwise render as a clean 0%, which reads as "this subsystem is free".
