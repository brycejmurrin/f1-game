Runs the real game in an iframe on this machine and attributes the frame time. Nothing is uploaded.

Every phase is measured on this same machine, back to back, with the render scale pinned and the performance governor switched off — otherwise the governor reacts to each phase and you measure its reaction instead of the cost. BASELINE is the shipped configuration; each row after it turns exactly one thing off. A large drop in median frame time when a subsystem is disabled is that subsystem's cost.
