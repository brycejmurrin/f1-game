This lesson uses synthetic braking runs to practise reading sampled traces. Open Data Hub Telemetry to compare real session data from OpenF1 with the same time and distance tools. The brake channel tells you when braking was reported, so use speed and position to work out what happened around that point.

Model and sources

Dots show the fictional samples at 0.25 s intervals. To estimate distance the model uses each interval’s ending speed across that interval. The speed line joins the sample points. Equal-distance arrival times use interpolation, so hundredths of a second are estimates. The binary brake state and sampled throttle each use a step trace that switches halfway between samples.

Brake onset and throttle return are estimated threshold markers from the game’s Braking Duel model. Minimum observed speed is a sampled quantity. The distance strip is schematic and carries no GPS or steering data.
