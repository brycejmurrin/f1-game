## Goal

Stands look alive under broadcast and flyby cameras: seated figures cycle a
few authored poses from a shared pose texture, each seat has its own phase, and
phones that cannot afford skinned crowds fall back to flipbook cards — without
blowing the props triangle / draw budget measured below.

## Non-goals

- Per-spectator AI, audio cheers, or crowd physics.
- Unique skinned meshes per seat (VAT or cards only).
- Changing stand shell / roof / barrier geometry (owned by scenery / stands work).
- Raising the pack 8 MB budget for a full character kit in this plan's first
  build slice (poses bake into one small texture + one card atlas).

## Design

### Technique (desktop / TLX·GLX·WGX capable)

1. **Pose bake.** Import a small Quaternius CC0 seated set (cheer / clap /
   lean / idle — ≤ 8 poses, ≤ ~300 verts each after prune). Bake each pose's
   vertex positions into rows of a `TEXTURE_2D` (or `TEXTURE_2D_ARRAY` layer)
   — GPU Gems 3 ch. 2 VAT. Ship as one AX26-adjacent blob or a tiny pack
   entry under `assets/pack/` with a CREDITS line.
2. **Per-seat phase.** Keep placing seats via `crowdBank`, but each instance
   carries a phase (`hash`-derived today) as an instance attribute (or packed
   into the existing tint/colour channel). Vertex shader: sample pose A/B by
   `fract(time * rate + phase)` and lerp.
3. **One draw.** Replace the 12-tri box model with the low-vert body mesh;
   keep `kind: "crowd"` instancing. Target ≤ **2 draws** for all seats on a
   circuit (same as today), triangles = `vertsPerBody × seats` (see budget).

### Mobile / low tier — flipbook cards

When the governor is low / phone / `apex26.crowdVat=0`:

- Draw a **camera-facing card** (2 tris) per seat, sampling a small RGBA
  flipbook atlas (same poses, billboarded).
- Phase still per-seat; no VAT texture fetch in the vertex shader.
- Optional: merge distant rows into one strip card per riser (LOD), cutting
  instance count further.

### Tiers (budget against today's measured cost)

Budgets are **caps relative to today's crowd-box cost**, not absolute GPU ms
(SwiftShader here is not a player GPU — AGENTS.md). Rebuild slices must
re-measure with `props-tris` + a live `__apex` / census pass on a real device
before tightening.

| Tier | Who | Geometry | Max crowd tris vs today | Draw target | Notes |
|---|---|---|---:|---:|---|
| **L0 off** | accessibility / debug | none (shell + riser only) | 0 % | 0 | `apex26.crowd=0` |
| **L1 cards** | phone / low governor | 2-tri flipbook per seat (or per-row strip LOD) | ≤ **40 %** of today's crowd tris | ≤ 2 | Default on mobile |
| **L2 VAT low** | mid desktop | ≤ 80-vert body × seats, 4 poses | ≤ **100 %** of today's crowd tris | ≤ 2 | Default TLX/GLX when not phone |
| **L3 VAT full** | high / broadcast cam | ≤ 200-vert body, 8 poses, 2-pose lerp | ≤ **150 %** of today's crowd tris | ≤ 4 | Opt-in; flyby/broadcast may force L2+ |

Worked examples from the Monza census (today ≈ 46 k crowd tris):

- L1 at 40 % → ≤ **18 k** tris (e.g. 3 835 cards × 2 = 7 670, headroom for
  atlas overdraw / distant strips).
- L2 at 100 % → ≤ **46 k** tris → body must average ≤ `46020/3835 ≈ 12` tris
  if every seat stays — so **prune hard** or **LOD**: near stands full body,
  far stands cards, so the *visible* peak stays near today's box cost.
- L3 at 150 % → ≤ **69 k** tris — only when a census on a real GPU shows
  headroom under the phone memory / frame governor.

Spa (27 k today) is easier; Monza is the gate.

### LOD rule (required for L2/L3)

Distance bands from the active camera (broadcast / flyby / chase):

1. **Near** (< ~80 m): VAT body (tier mesh).
2. **Mid**: cards or decimated VAT (half verts).
3. **Far** / not in frustum: skip seats; keep riser slabs only.

Re-use the existing props cell / chunk bins — do not add a second culling
system.

## Risks

- **Triangle creep:** a 100-vert body × 3 835 seats ≈ 128 k tris before LOD —
  **over** the L2 cap. LOD or seat decimation is mandatory, not optional.
- **Pack bytes:** pose texture + atlas must fit the 8 MB pack verify; prefer
  quantised poses and a shared atlas.
- **Backend parity:** three shader ports (GLX/TLX/WGX) or the feature stays
  off on the missing backend.
- **Concurrent scenery PRs:** stands-curve / kit-swap hunters own related
  scenery files — crowd VAT slices must touch only the crowd instance path
  and merge origin if those land first.
