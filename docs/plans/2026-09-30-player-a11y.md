## Design principles (every slice)

1. **Own-state / assist-gated.** Grip steer never reads curvature. Audio
   cues may, only behind an assist that defaults OFF (or is part of ROOKIE).
2. **New modules, thin hooks.** Logic in `js/physics/`, `js/audio/`,
   `js/ui/`, `js/car/` — `game.js` gets call sites and `G` façade members
   only; extract equal bulk if a façade add would grow the file.
3. **Schema ladder, not silent defaults.** New stored keys that change
   behaviour for existing players go through `STEER_SCHEMA` (or a sibling
   migration) + SPEC + a behaviour test that fails before the change.
4. **Shell / CSS budgets.** Prefer CSS variables and existing dock /
   title nodes. Net new shell nodes ≤ slack; net new cssClasses ≤ slack.
5. **No ratchet raises, no quarantine growth, no loosened tolerances.**
6. **Deep links stage, never start.** Apply payload → open the right
   picker / garage sheet; `startRace` / `gridUp` remain the only path onto
   the grid.

### Slice 1 — Grip-steer assist (S–M) — BUILD FIRST

**PR title:** `player-a11y: grip-steer assist (own-state, default OFF)`

**What ships**

- New pure module `js/<new>/physics/grip-steer.js` (`window.GripSteer`):
  `assistK(level)`, `capDelta({…own state…}, k, out)` implementing §4.1
  (αpk, capIn / capCtr, self-centre, speed smoothstep 2–6 m/s). No
  `Tracks`, no `curvature`, no `kCur`, no `ROAD_FOLLOW` write.
- Call site in `updateCar` immediately after `driverDelta` is computed:
  `driverDelta = GripSteer.apply(driverDelta, …)` when `k > 0` (slider),
  else identity. Must not touch `assistDelta` / `lineDelta`.
- Store key `gripSteer` (1 = OFF). `PRESETS`: `rookie: 8`, `relax: 6`,
  `standard: 1`, `pro: 1`. `PRESET_STORE` + ADVANCED slider `#pm-gripsteer`
  (reuse an existing ADVANCED row pattern; prefer replacing dead chrome
  before adding a shell node).
- `STEER_SCHEMA` 4 → 5: unset → 1 (OFF). Existing stores stay OFF unless
  they pick ROOKIE/RELAX after the change.
- SPEC row in `settings-export.js`. `docs/PHYSICS.md` note that grip
  steer is **not** a curvature consumer (source-regex test pins it).

**Tests / measurements**

| unit: source-regex — the new grip-steer module has no `Tracks` / `curvature` / `kCur` | if someone wires the road in |

## Build order & PR discipline

```
docs-only plan PR  →  slice 1  →  slice 2  →  slice 3  →  slice 4  →  slice 5
```

After every push: `node tools/ci/ci-watch.mjs --sha <head>`; on red,
`ci-red-triage` then fix at root. Sync to ship only on conflict or tip-red
required check (`sync-pr.mjs`). Claim via `who-is-on-it.mjs --claim` while
actively editing shared files (`steer-tuning.js`, `hud.js`, `game.js`).

Pre-push ladder per slice: all source edits → `tooling-fast` →
`deploy.mjs --gate-only` → commit → push → draft PR → watch → undraft when
full tier green on that head.
