  minimum 28×28 pt. https://developer.apple.com/design/human-interface-guidelines/accessibility
- WCAG 2.2 SC 2.5.8 Target Size (Minimum), 24×24 CSS px with the spacing exception:
  https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html ; 2.5.5 (AAA) 44×44:
  https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html
- Dynamic Island iPhone landscape insets ≈ 59 / 59 / 21 (iPhone 14 Pro); they need `viewport-fit=cover`:
  https://useyourloaf.com/blog/iphone-14-screen-sizes/ , https://bugs.webkit.org/show_bug.cgi?id=272779
- Thumb zones (top centre is the hardest reach; no published two-thumb landscape map):
  https://shop.smashingmagazine.com/2016/09/the-thumb-zone-designing-for-mobile-users ,
  https://gamedeveloper.com/design/how-to-design-for-thumbs-in-the-era-of-huge-screens
- `font-variant-numeric: tabular-nums`, Baseline widely available:
  https://developer.mozilla.org/en-US/docs/Web/CSS/font-variant-numeric
- Xbox Accessibility Guideline 101 (minimum text size on mobile):
  https://devdocs.xbox.com/build/game-principles/accessibility/xag-deep-dives/xag-101-text-display.md
- Racing-game mobile HUD conventions (Real Racing 3, F1 Mobile Racing, GRID): no primary source found
  for their default placements or pause layouts. Nothing here relies on them.
