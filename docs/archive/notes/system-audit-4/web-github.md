## GraphQL batch (Q5): 50 PRs in one call, cost about 1 point
```graphql
query($o:String!,$r:String!){ repository(owner:$o,name:$r){
 pullRequests(states:OPEN,first:50,orderBy:{field:UPDATED_AT,direction:DESC}){
  nodes{ number title body isDraft mergeable mergeStateStatus headRefOid baseRefName
   labels(first:20){nodes{name}}
   commits(last:1){nodes{commit{statusCheckRollup{state
     contexts(first:50){nodes{__typename ... on CheckRun{name status conclusion} ... on StatusContext{context state}}}}}}} }}}}
```
`mergeable` can be UNKNOWN on first read (async computation); re-query. Nested first:50 x first:50 x first:20 is ~2,500+ nodes, far under 500k. Not executed (no token use here); syntax is from the documented schema, unverified live.
