## Clean (checked, fine)
- TLX track change: freeInstancedBatch (tlx.js:2398-2425) splices _instRegistry, removes and disposes the main and mirror meshes, frees the geometry, and drops the _shadowPack. The tlx-shadow casters are parked on parkedGeo (tlx-shadow.js:324-329), so the old track's geometry is not pinned.
- mirRT and _blitRT are sized once and resized with setSize. The mip grow path disposes and re-allocates lazily (tlx.js:1481-1487, 4464-4474). The lampGrid is three fixed-size float textures allocated once (tlx.js:1679-1697, about 0.85 MB). The fixed size is deliberate: no node-graph rebuild on a track change.
- tlx.js begin()/draw()/present() hot path: the allocation grep over 5768-6500 finds nothing per frame. The only allocations are in the lamp-grid rebake (key-gated) and diagnostic paths. The lamp colour refresh uploads only the lamp rows, rounded to 64 (A3, tlx.js:1732-1747).
- tlx-post.js: the SSAO, godray and bloom targets shed after 8 idle frames (SHED_FRAMES, :419). Each release rebinds the 1-px fallbacks before dropRT. present() restores autoClear in a finally block.
- TLX onDeviceLost (tlx.js:1043-1110) handles three cases. A hidden loss waits for visibility and is not counted. A loss within 3 s of a visibility return reloads without being counted. A visible loss writes the envProbeOff/perChunkOff latches, which have a clear path (light-tune-edit.js:22-34, apex.js:1201). WGX mirrors it (wgx.js:793-845).
- assets.js degrade path: a manifest 404 or bad JSON gives tier "off". A failed normal strip is survivable (albedo alone). A failed albedo upload calls _discardLoad. Generation checks cover every await. modelsReady resolves -1 at 4 s and never rejects (:918-925). Layer index = MAT id: present[]/scales[] are indexed by L.mat in 1..16 (:606-611), and MAT_LAYERS=17 holds all three backends to the same layer count.
- iOS limits: the pack is 17 layers at 128 px on phones (wantLow = isMobile; manifest low.size=128), well under the WebGPU default maxTextureArrayLayers of 256. Depth is depth24plus (WGX) or three's default, not 16-bit. TLX resize clamps to device.limits.maxTextureDimension2D (tlx.js:4357-4367). The tlx-shadow caster UBO pad keeps casterAttr on by default on phones (tlx-shadow.js:274, 410), so a phone does not mint one program per batch.
- GLX post: abandonTargets/createTargets bind each FBO before deleting its attachments, so no old and new target sets stay resident together (post.js:230-300). Texture-array OOM or a bad layer falls back to a grey page (glx.js:1288-1299).
- Night lighting: no resolved `*|night|*` preset has lampLevel ≤ 0, and day/dry never exceeds 0.05. The floods are never forced off by the data.
- car-draw.js hot path: cockpitMirrorGlass is memoised (car-body-geom.js:1103-1112). Matrices are scratch Float32Arrays (car-draw.js:1230-1234, 1365-1382). glassState's .map chain runs only on __apex demand.
- There is no `.claude/rules/render-glx.md`. Only render-tlx.md and render-wgx.md exist, so the GLX parity rule cited in the ask is absent.
