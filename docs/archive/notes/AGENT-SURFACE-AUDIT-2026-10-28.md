## Proposals for Bryce

- **P1 (tool):** teach `needs-sync.mjs` the gate's distance row for game-touching PRs (reuse `distanceFor` from
  merge-gate.mjs), so its verdict and `sync-pr`'s exit 4 stop contradicting the gate. Out of scope for a docs PR.
- **P2 (policy):** now that AUTO-SYNC exists, decide whether agents should ever sync a ready `land` PR by hand
  on distance, or should always leave it to AUTO-SYNC (`SYNC_MAX: 3` is the throttle; 2026-10-28 had ~15 PRs blocked
  on distance, which is more than one train's budget).
- **P3 (size):** trim AGENTS.md rows 1-9 to their pointers and move rows 10-13's figures to the notes they cite.
- **P4 (policy):** AGENTS.md rule 4 could name the 7200000 ms ceiling for every known >30-min task (sync-pr,
  `deploy.mjs --gate-only`), not only in steward.
