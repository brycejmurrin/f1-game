# Archived move plans (applied)

Historical `move-tree.mjs` plans from the 2026-09 tree restructure. These are
records, not live inputs. Most have missing `from` paths; the reversed WGX/TLX
spike map uses the deliberately unsupported `appliedMoves` key so it cannot
move the restored backends out of the product again. Live plans, when any
exist, belong in `tools/moves/`.
