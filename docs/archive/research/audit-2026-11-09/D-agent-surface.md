## 1. Summary

What this slice actually is: a three-layer steering system. (a) Prose: AGENTS.md (8.7 KB, 13 rules), 6 path rules, 39 skills (188 KB of SKILL.md plus ~130 reference files), 11 subagent cards, 2 workflow scripts, 12 memories, 30 decisions. (b) Local guards: 10 Claude hooks plus thin Cursor/Codex adapters and 4 git hooks. (c) Server side: `dispatch.yml`/`dispatch.mjs` (launches paid workers from issue/PR state), `land.yml`/`merge-gate.mjs` (merges on a `land` label behind one required status, `gate`), and a phone bridge that drives the owner's iPhone through issue comments.

Health, as found rather than as documented:
- The mechanical mirrors are in good shape (skills symlinks, rules md→mdc generator, MCP configs, nested AGENTS.md) and are really test-guarded. Host-config keys are almost all real (`onFailure`, `SubagentHandback`, SubagentStop matchers all exist).
- The local guards are **advisory, not enforcement**. Every "(hook)" rule holds only for its canonical spelling: a leading space, `if …; then`, `gh -R`, the REST route, or a differently named launcher walks past. A subagent can start Chromium by at least 20 named routes, create the protect-files hatch, or edit the hooks themselves. Several false positives block ordinary read-only work.
- A whole-tree rollback on 2026-11-06 (88c25da) silently reverted the 11-03..11-06 hardening (issue #4561 and six others) while the issues stayed "closed completed" and docs/skills/DECISIONS still describe the reverted behaviour (receipt hook, `/mcp?token` refusal, isolation guards). This is the single largest source of drift.
_(one line withheld: security detail, kept in the owner's private page)_
- Skills: 2 KEEP, 37 FIX, 0 dead commands of consequence, but a systemic contradiction — ~20 skills tell agents to run a browser spec locally (`test-bg.mjs --spec`), which AGENTS.md rule 5 forbids and docs/VERIFICATION.md §3 still prescribes. 8 skills with `paths:` are invisible in a fresh chat although 18 other skills route to them.
- Net: the process is producing more drift than protection. The text is mostly accurate about the *game*; it is least accurate about *itself* (which guard exists, which tier runs, who may do what).
