## Method

For each merge `M`: files from `git diff M^1 M`; the share of its added lines (≥ 25 chars) still in the same file at
the tip; then a per-PR read by one of twelve reviewers (≈ 25 PRs each): 1–3 distinctive added lines or test names
checked with `git grep -F` / `git log -S … d921fd52..HEAD`, the PR body and closing issue read on GitHub (read-only),
and the docs/changelog/skills grepped for a "fixed" claim. `git cherry-pick -m1` of every merge was dry-run on the tip:
153 apply cleanly, 134 conflict, 3 are empty. "Open PR touching" uses the file lists of the 64 open PRs on 2026-11-10,
ignoring generator outputs (`tools/lib/generated-paths.mjs` GENERATED_PATHS, docs/NOTES-INDEX.md) and the
append-only registry tests/groups.json.
