# Look-survey contact sheets

One 4×5 sheet per circuit: rows `dawn / day / dusk / night`, columns
`dry / wet / rain / fog / overcast`. Built by
`python3 tools/look-survey-sheet.py --ready` from `artifacts/lighting/shots/<id>/`.

The fleet is 40 circuits × 20 looks = **800**. Sheets land here when a track
hits 20/20. Remaining tracks stay at the first-pass 4 (or mid-survey) until
`survey-batch.py` finishes them.
