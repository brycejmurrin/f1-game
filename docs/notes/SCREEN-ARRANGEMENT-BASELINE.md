# Screen arrangement baseline

Kind: design

The deployment branch was fetched at `f8970a989e91055231703865d6f5596f6d44be74`. Existing layout data has four independent owners. Title owns its portrait and landscape groups, HUD owns profiles and camera groups, Dock owns per-scheme touch controls, and ScreenLooks owns individual screen appearance settings.

The first visual baseline entered Career Modes from the title menu with empty career slots. Build 1695 was captured in Chromium at 844 × 390 CSS pixels with the repository’s landscape handset preset. This provides a reference for testing region width separately from scale.
