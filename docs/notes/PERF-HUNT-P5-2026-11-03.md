## Refuted / clean (do not re-hunt)
- `#hud-tyre-fill` `transition: width` (`css/hud.css:653`): already measured as not the cost (#4270 §5, #4316: 0–1
  writes per 5 s).
- `backdrop-filter`: no live HUD rule (only comments at `hud.css:108/253/1207`, `touch-controls.css:977`). The opacity
  `pulse` / `along-pulse` keyframes composite; `will-change` only on `.pc-nub`.
- Visor refraction `filter: url(#visor-bend-*)` on the world canvas (`css/helmet-visor.css:36-39`): opt-in
  (`visorRefraction` defaults to `off`, Bryce's export does not set it) and already budget/shed-gated (P1 slice).
- `js/ui/scale.js:261-266` `documentElement` style MutationObserver → `refreshBtnFit`: one rAF-coalesced inline
  `getPropertyValue` and a dirty-checked `textContent`, no layout.
- Menus: loading-screen timers/listeners stop on race entry; dock-layout pointermove returns unless dragging; the
  select-screen detail ResizeObserver disconnects; title-layout / modal observers watch one attribute; scroll and resize
  listeners are passive.
- HUD 10 Hz tick: hText/hAttr/hToggle caches, HudDamage/HudTyres signatures, HudStrategy/HudRelative row caches, the
  minimap's cached background are all dirty-gated.
