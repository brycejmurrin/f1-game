### 1. Dialog `:has()` scope

Every shell `<dialog>` is a `<body>` child; the one built at runtime (the Data Hub telemetry popup,
`js/data/telemetry.js`) is appended to `#datahub`. So the two rules split into a body-child form and a
`> :where(#datahub) > dialog` form, the same match; `:where()` keeps specificity.

Body-restyle micro-bench (`scratch/p2/bench.mjs`): in the live phone-shape race page, toggle `body.hud-tyre-stack` (the
class the HUD fit flips) 300 times, each followed by a `getComputedStyle` read; interleaved base/new, 3 pages each:

| arm | p50 ms | p90 ms | mean ms |
|---|---|---|---|
| base | 3.7, 3.7, 4.0 | 5.6, 4.2, 5.7 | 4.10, 3.83, 4.31 |
| scoped | 2.2, 2.2, 2.2 | 2.5, 3.1, 2.5 | 2.22, 2.36, 2.26 |

A body attribute that only an attribute-presence rule reads (`data-radio-corner`) costs 0.1 ms in both arms, so the gap
is the body-subject `:has()` re-match, not the bench. The per-frame trace mean dilutes it (body restyles on about a third
of frames): quiet-box pair 2.03 → 1.61 ms/frame of `UpdateLayoutTree`; the other two pairs ran beside the commit hook's
guard suite and are not comparable.
