## Fixed here (#3)
`paintDock(true)` from `tickScrub` returns early when nothing it reads changed (`scrubT`, play state, rate,
`sheetBusy`, ring head/count, a tag revision, `G.paused`, `allowed()`); every user action still repaints.
`adjacentFrame` is a binary search over the chronological ring (`sample()` clears on a clock rewind, as
`frameIndexAt` already assumes). Test `replay-buf` "a paused or stopped replay does not repaint the dock every
frame": 13 lookups/frame → 0 over 60 stopped frames (fails before). "frame step lands on recorded timestamps
across uneven spacing and the ring wrap" pins the search to the old scan's answers.
