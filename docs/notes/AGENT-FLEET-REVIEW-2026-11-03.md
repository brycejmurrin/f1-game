### What worked (keep)

- **Claims and stand-downs.** `017Yzwxx1GN1` saw the newer `owner:` line and stood down without editing (5c8a8692).
  The CONTINUE workers saw the existing `adopts` comment and did not re-adopt.
- **Hook refusals were mostly right and cheap**: `pkill -f`, `sleep`, `git reset --hard` (classifier), a subagent
  starting a browser, and the five merge attempts on #4597. Each cost 1–2 turns, and the worker adapted. The run-cancel
  refusals held even after Bryce granted it in chat, which is correct per AGENTS.md (his click is the grant). D then
  handed him the run links (10:25).
- **The PR template was followed** (Goal, exactly one `**now:**`, the trailing `land:`, the Hand-off fence) in every
  Sonnet PR read.
- **Opus fix clusters were tight.** #4571, #4570, #4577 and #4287 each showed a failing-then-passing regression test.
  #4571 re-ran one flaky shard once and named it in the PR (rule 9). Hunts found real defects (B3 fixed 13).
- **No worker parent polled CI.** Every worker ended its turn after `subscribe_pr_activity` (the `sleep` loops in finding
  21 were inside subagents). The waits that started as `sleep` were
  blocked and moved to Monitor or notifications.
