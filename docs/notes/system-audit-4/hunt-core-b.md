## Clean (checked, fine)
- sw.js install: version.json and index.html are both read no-store and cross-checked (`shellBuild !== build` throws, sw.js:714). A Pages deploy that lands mid-install aborts that install, the old worker stays in charge, and the next navigation retries it. Nothing gets stranded.
- Mid-train phone (shell N, network N+1): the navigation is network-first with no-cache, so the shell comes from N+1. Every `?v=<12hex>` key names its own bytes, so an unchanged file hits gen N. A changed file misses, goes to the network, is hash-verified (sw.js:1105-1110) and is filed by content. If the shell is the offline fallback (N), gen N already holds every essential for N, so nothing mixes. A skewed body becomes Response.error, never wrong bytes.
- DEFERRED precache: TLX/three are stamped with the shell's lazy hash (`stampKey`, sw.js:722), GLX + career UI are in the required set, and WGX is runtime-only (isRuntimeOnlyOptional). The stamp regex covers every ScriptLoader class. The importmap vendor files stay bare by design.
- Sweep/retention: activate and the fetch path share one guarded sweep (SETTLED-only, keeps one prior settled gen while a window client exists). Order memo is invalidated at every marker write. No rejection is memoised (currentCacheName/cacheOrder).
- iOS quota: the "50 MB cap" is obsolete. Since Safari 17, the per-origin quota is up to 60% of disk for browser and Home Screen apps alike. Eviction is whole-origin LRU, and Cache API data counts toward it (webkit.org/blog/14403). index.html:237 already requests `navigator.storage.persist()`.
- js/track engine `_sceneryShift` consumers: bridges (tracks.js:128, surface.js:82, build-props.js:2181), elevations (tracks.js:137), undulation (tracks.js:166), bankZones (mesh.js:202, with mirror), dressingExclusions (build-props.js:1257 via sceneryRange), otDetectFrac (overtake-mode.js:40), scenery api (build-props.js:2070 transformSceneryApi). Each table is shifted exactly once. def.js:264-293 does fmap+dress on purpose (its comment documents the 2026-08-13 regression).
- Per-circuit `_sceneryShift` idioms: all 18 `sceneryStartFrac` circuits checked. SL=1-shift is used in 14 files; singapore uses SL=shift (mirror); monaco uses startFrac+shift (reverse); hungaroring uses au()/explicit `-shift` (:26, :849-853); bahrain uses `turns[i]-shift`. No raw `def.turns[` read in any scenery file skips the shift (grep: 0 hits).
- js/track has no circuit-id literal outside generated circuit-meta.js (grep over all 52 ids).
- Sim RNG: game.js:569-607 owns the seeded stream. The remaining Math.random calls are fx/audio/particles and season-cal:697. Wall clock on sim paths: none. brake-cue.js:73 is the HUD cue; quali-net uses peer timestamps.
- Ghost/InputGhost: Date.now is used only for LRU access stamps and the idle-flush budget (ghost.js:52/69/279, input-ghost.js:29/294/408). Store iteration sorts keys before eviction (input-ghost.js:325).
- apex.js read hooks (info/probe/scan/physState/obs/lightState) do not write game state. `smp` scratch is reused, but hooks run between frames.
- Manifest load order: FULL is a valid toposort of the derived eval edges (scan-globals --check exit 0).
