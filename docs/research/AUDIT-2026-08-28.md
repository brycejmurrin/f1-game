# Whole-tree audit synthesis — 268 verified findings (2026-08-28)

## Verdict

The cleanup campaign did what it set out to do on the *structural* axis — load order, module extraction, guard suites, the `G` façade and the docs index all hold, and 0 of 268 findings were refuted by the skeptics. What it did not touch is now clearly visible: the remaining mess concentrates in four places. (1) **Agent-facing truth** — the `__apex`/`world()` payloads, `docs/DEBUG-HOOKS.md`, `types/game-ctx.d.ts` and three `.claude/skills/` files ship measurably wrong numbers, wrong signs and wrong domains, including a `new-track` skill that mirrors every corner it authors; this is the same class as AUDIT-SYNTHESIS FIX-NOW #3 and proves that sign/units fix never propagated past `js/`. (2) **The net stack and its worker** — `js/net/` carries the only cluster of genuinely dangerous defects in the tree: unvalidated wire fields that NaN the countdown or rank a rival first, a `pump()` that dereferences a cleared inbox, and a Durable Object whose TTL wipe can be deferred forever by an unauthenticated POST. (3) **`js/circuits/` orientation** — five circuits build scenery with an inverted or swapped basis, and because the guarded emitters cull silently, four of them render nothing while the comments describe geometry that has never existed. (4) **`tools/` and generated docs** — the lighting slider tables are 153/184 and 75/91 rows out of date, six WebGPU tools override the harness's browser pick with a path that does not exist on this box, and `tools/assemble-ci-yml.sh` destroys the live workflow if run. The single most alarming finding is not a bug at all: `assets/pack/` and `tools/assets.mjs` disagree about whether the shipped asphalt layer is a CC0 photoscan, which is a licence-provenance question, not a style one.

## Fix now

Ordered by severity. **Batch A** touches `js/`, `css/`, `index.html`, `sw.js` — land as commits grouped by area, then ONE `node tools/bump-cache.mjs --apply` as the last edit. **Batch B** touches docs/tools/skills/config/worker/spike — no bump.
