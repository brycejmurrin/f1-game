# Bug hunt 2026-09-02 — read-only agents, two fix batches

Five read-only subagents (no edits, no browser) traced the tree in parallel
while a deploy ran: UI, GLX, WGX+TLX, memory/CPU outside the renderers, and
race-flow logic. This file is the ledger: every CONFIRMED row, what landed in
the fix batch (commits named at the bottom), and what was deliberately left.
Rows marked PLAUSIBLE were not verified in code by the parent and are not
landed. "Verified" below means the parent re-read the cited code before the
fix; "unverified" means the fix is landed on the agent's trace plus a guard
suite, not a browser run — those are named as such in the commit.

### Not landed (named, with why)

- **Downhill clamp confiscates a player's overspeed** (`c.speed = min(vmax·1.06, …)` on any descent, CONFIRMED: 85 → 63.4 m/s in one step at Monza frac 0.05): the physics-characterization browser baseline PINS the snap — "trail brake into rotation" starts at exactly 1.06·vmax — so the fix is a re-baseline with a browser run and a decision on whether ERS/X-mode overspeed should persist above vmax at all (row below). Left in place with a note at the site.
- **No drag above vmax on the throttle** (speed between vmax and vmax+14·PACE holds forever on a flat road; closing X-mode never slows you; a VSC delta binds only cars already slower): same decision as above — a rate-based decay toward vmax changes the ERS margin's meaning and the baselines.
- **Rear-end impulse fires once per relaxation pass** (4 impulses per step; a 20 m/s closing tap put +11 m/s into the car in front, CONFIRMED): gating it on the last pass turned two collision liveness pins red (`collisions-vm` "jammed pack digs out" 11.97 vs > 12, `collisions-deep-vm` traffic-nest min speed 7.7 vs > 18) — the pack dig-out depends on that exchange. Needs a retune of `jImp` with those two pins as the gate, not a one-line gate.
- **Zandvoort horizon dunes** (33 of 66 dropped): sizing each dune to `(dist−2.6)/1.061` changed nothing — the drops are parallel legs within reach, not the dune's own foot; a data pass per site.
- Net: two guests picking the same seat livelock (`blockingSeats` ignores rank); remote `finishT` stamped at pose time (+100 ms interp) and latched from an extrapolated wrap; START dropped for a guest still inside `startRace()` after `ARM_WAIT`; second answer to a shared room code never replayed; `since: now()` vs a fast guest clock; hub close aborts nothing; `Retry-After` capped at 25 s; quota purge by age not size — all real, all bigger than a row.
- Physics: weather-arc grip steps 18 % in one frame (needs a blend); reverse-crawl slip sign; `stoppedOnTrack` rescues a parked touch player; OT proximity uses classification not road order; AI `bankMu` vs player; `_lapCross` sector reset.
- Input/audio: boot `_govCool` masks a steady-slow device; iOS gyro permission rejected by a synthetic pad click persists `steerMode`; `usingSamples` decided once; photomode `pointerleave` release; `pad.mapping` unread.
- Track data: `cityFront`/`pastelStreetRow` `depth` is the frontage (Monaco/Baku sliver towers); marshalPost gap-to-centre < 3 on monaco/jeddah/baku; bahrain masts/fence on the return leg; Suzuka crossover fence holes; shanghai/jacarepagua rows over parallel legs; duplicate kerb ribbons; backdrop slabs crossing other legs.
