# Complete tools root and miscellaneous source map

Static inspection on 2026-10-27 of every tracked file directly in `tools/` and recursively in `tools/agent`, `archive`, `assets`, `desktop`, `docs`, `hooks`, `net`, `transcripts`, and `viewer`: **42 files, 535,847 bytes, 8,723 lines**. All are UTF-8 text; there are no binary payloads or symlinks in this scope. Every line was read; oversized initial outputs were reread in bounded sections. This is a source map, not a runtime validation. No project CLI, test, browser, Blender, network probe, git mutation, or source edit was performed. Only this report was written. Governing instructions read: root `AGENTS.md` and `.claude/skills/code-nav/SKILL.md`; no nested tools AGENTS file exists. These files are outside `js/`, so text/import inspection is appropriate under code-nav.

## Ownership and execution boundaries

`tools/manifest.cjs` owns ordered runtime rosters, path constants and migration aliases. `tools/README.md` is generated from tool header tags by `tools/gen/gen-tools-readme.mjs`; its tables are navigation, not proof a command runs. `tools/carview.html` has generated script tags from manifest CARVIEW; `tools/gen/gen-shell.mjs` owns that block. Change authoritative inputs, then regenerate. Neither generated file was edited.

`tools/agent-run.mjs` owns terminal command presentation. It delegates subprocess ownership to `agent/process.mjs` and artifact storage/paging/MCP presentation to `agent/output.mjs`. MCP output-level wrapping separately consumes the same helpers. Output records belong to the wrapper; a summary's test counters do not replace its subprocess exit/status.

`tools/desktop/stage-files.mjs` owns the runtime shipping allow-list shared by Pages, Electron and mobile staging. `stage.mjs` copies/stamps it; `minify.mjs` and `minify-worker.mjs` transform only the staged JS before stamping. Desktop application/runtime/version ownership remains under `desktop/`, outside this scope. The asset tools validate or author local assets; they do not silently install them into runtime packs. The transcripts tools are a separate streaming JSONL utility, with no game or hosted transcript service dependency. The viewer is a generated standalone inspection page, distinct from the GLX studio and the game shell. Network tools are manual integration probes, not substitutes for the normal fake/loopback test groups. Archive tools preserve dated measurement implementations and are explicitly unmaintained.
