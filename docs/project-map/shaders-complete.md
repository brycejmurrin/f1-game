## TLX lit graph and contracts

`tsl-lit.js:66–180` establishes factory-time capabilities: lamp cap from `ctx.maxLights` or LightBudget.MAX, shared textures/uniforms, optional shadow maps, SSR tag support, env cube, material maps and lamp grid. TLX's caller supplies LightBudget.LITE on lite GPUs and MAX otherwise (`tlx.js:1710–1713`). Loop bounds and CPU lamp arrays share this cap. Local-storage switches choose analytic road normals and shared texture grouping. Capability switches determine graph shape; runtime uniform switches avoid rebuilding it.

The standing rule is load-bearing: shared varying-derived TSL nodes must acquire unconditional Fn-body `.toVar()` anchors before conditional first use, or WebGL code generation can strand their assignments in a branch. The fragment anchors world/object positions, raw geometric world normal, color, material and optional track coordinates; hammered cotangent derivatives are also unconditional. Derivatives must remain in uniform control flow for the WebGPU route. Uniform material gates may contain derivatives; varying material-ID gates consume already-computed footprints.

`U` holds the shared frame nodes, including lighting/fog/tune defaults, pit lane/box, shadow matrices, lamp grid and bake atlas state. Most scalar tuner writes skip unchanged values with `uf1`. `updateFrame(frame, mirror)` applies ambient multiplication and fog/mist controls, derives wind, zeroes env strength for the caller's later probe-ready update, gates shadow strength on live subsystem state and key luminance/moon floor, and unpacks stride-15 lamp records. Position 0–2, color 3–5, radius 6, direction 7–9, cone/bleed 10–12 are the lit lanes; live-only metadata is recovered through LampBake. Mirror lamp shadow is disabled because its ranked light slots differ from the forward list. Mirror per-chunk lamp cap does not replace the global frame count.

Shared frame nodes use `renderGroup`, not `frameGroup`, because shadow/env/main passes are separate render calls with intervening updates. Texture nodes also share renderGroup where enabled, and swappable base nodes preserve program identity. Per-object material values stay out of that shared frame block: a single object-update callback feeds emissive/alpha/road selection and two packed material vectors. Material cache identity and node-graph identity are separate requirements.

`setLampGrid` validates lamp count, concatenated indices and occupied grid dimensions against fixed allocations, packs each lamp into four RGBA texels, and uses LampChunks.blitGrid for row-stride-correct grid placement. Invalid input leaves lgOn zero and global lamps remain available. `setLampGridColors` refreshes only lamp color texels after the track's allLightsGen signal. Chunked fragments select their own world-XZ grid cell; ordinary road draws can opt in through both frame and draw flags, while instanced draws keep global lamps. Missing/empty/outside cells fall back to global lamps. This is deliberately **per-fragment** selection, unlike WGX's per-draw index slice. TLX disables mapped-lamp shadow comparison on the grid path because a frame slot is not a track-light index.

`setLampBake` owns half-float diffuse/bounce tile-atlas textures and nearest indirection. Identity-stable placeholder nodes retain the correct final filter kind even before the first bake. Atlas alpha stores ground height; tile origins use -1 for empty and gutters prevent cross-slot filtering. Upward fragments near the baked surface take full baked diffuse/bounce, while live lamps step aside by bakeW unless live-only. The mapped lamp carves its occlusion out using the bake's steady shadow color; final color is clamped above black. After more than 120 inactive updates the real bake textures are disposed and placeholders restored.

Material IDs 1–16 use procedural relief and albedo; glass/flag have selective exclusions, asphalt is 16. Wall-like materials use `(dominant horizontal coordinate, world y)` and ground uses XZ. Near relief fades over 22–80 m with footprint guards; albedo uses farther 90–260 m modulation. The default road-normal-v2 path uses analytic noise gradients for ground micro-normal/asphalt, while the old finite differences remain an A/B option. Baked albedo/normal arrays compose on the procedural result, gated by matTexMix and per-layer scale. IDs are clamped only for safe array access and tested against the real 1–16 range so car IDs do not consume pack layers. `setMaterialMaps(null)` clears scales without rebuilding nodes.

Road markings consume `trk=(arc s, signed lateral x, half-width)`; hw <= .5 suppresses them. Chunked graphs omit the attribute entirely. Raw lateral footprint drives the mip fade; capped footprint drives line AA. Edge paint, 7 m/50% dashed center paint, wrapped blue pit boundary, entrance bar and own-box rails/end bars overlay the textured road. Lane width follows the 3.2 m maximum / 2.4 m minimum / 7 m racing-space rule. Pit lane length zero and box half-length zero mean absent.

Car IDs 20–44, plus reserved finishes 60–85, classify paint/carbon/rubber/sidewall/metal/glass/visor/emissive/panel and expanded finishes. Reserved finish IDs remap to existing optical base branches and tint after lighting. Procedural car patterns use object space so they move with the car. Clearcoat uses a geometric-normal snapshot; orange peel, weave/hammer bumps and material bumps affect the base shading normal. SAA uses the pre-material bump snapshot. Wet world ground darkens and can polish/puddle; porous materials darken without wetSheen; cars instead receive a uniform wet treatment on dull surfaces, never world-keyed puddles/ripples.

Lighting order is hemisphere ambient and shadowed Lambert, baked/live punctual contributions, sun GGX, clearcoat sun and energy-conserving env mirror, sparkle, glossy/wet env, metal env, finish tints, rim/contact darkening, emissive HDR glow and fog. The sun shadow uses slope bias, gliding eye-XZ/look-Y fade, Poisson 8 near / 4 far taps, optional blocker-scaled radius, and car-map min-combine. No-blocker and blocker-disabled paths scale R=3 by pcssPen/80. The spot loop rejects by squared range and attenuation before expensive work; Smith view roots are lazily cached per fragment. Fog combines height attenuation, capped solar in-scatter, lamp Reinhard glow, warm/cool tint and drifting ground mist.

`makeMaterial` shares six possible graphs: plain/chunked/instanced × base/fx, with fx requested for the reserved finish range and refused on chunked materials. Node materials disable three lights/fog/vertex colors and pin stable program families; MRT presence and metadata-preserve mode participate in the key. SSR metadata is distinct from real opacity: .35 paint, .75 opaque porous world, otherwise material alpha. Main HDR MRT writes the receiver tag separately; canvas/env passes disarm MRT. Translucent/noAlphaWrite materials preserve destination metadata through attachment-specific blending. Opaque materials explicitly use NoBlending. Chunked transparency retains depth writes to match GLX. The noDepthTest garage reflection remains in the opaque render list with its custom blend so submission order can clip it correctly. releaseMaterial removes an evicted material from the MRT registry. Debug material modes expose normal, material-ID palette and raw lamp pools. DecalLight exposes shared static-shadow and baked-pool nodes to tsl-fx.

## TLX post graph

`tsl-post.js` returns materials/nodes/uniform handles, while tlx-post owns targets and execution. Every pass uses a fullscreen overwrite material with depth/lights/fog disabled and stable cache key. Optional viewport wrappers map logical views onto fixed targets; absent wrappers are identity. Helpers express manual GL-space UV/depth reconstruction and flip into three's top-left texture space. Perspective scalars replace full matrices for supported perspective shapes, including garage lens shift.

Bright threshold is tested after exposure but returned bloom remains scene-referred. Bloom downward filtering is 13 taps, with Karis on the first downsample; upward filtering is a 9-tap tent. Intermediate up passes add, final level zero overwrites to avoid reinjecting sharp bright pixels. Fixed per-mip materials avoid changing sampler identities every present. AO and godray blur families are separate by target format; blur can carry folded AO in alpha.

SSAO uses eight directional taps and a five-step contact march with receiver-plane self-occlusion rejection. Position/normal derivatives precede the sky test. Godray exists only with a sun shadow texture: sixteen world-space steps with Beer-Lambert extinction, sun-map/cloud modulation and at most six aimed lamp beams with mapped-lamp carve. It can compute the same SSAO term in alpha before varying march flow. Shared uniforms connect the folded AO and the bilateral composite upsample. Unique placeholder texture identities prevent three collapsing independent bloom/godray samplers.

Composite applies haze, chromatic aberration, radial blur/sharpen, bilateral AO and volumetric light; SSR is embedded directly in this pass. Tag masks distinguish paint, porous world and sealed world. Road quality chooses 24/16/8 march steps, 4/2/1 refinement, and narrower far range; car-dominant pixels keep full quality. Normals reconstructed with a three-depth-texel baseline fall back on conditioning to the supplied road plane. Road rays flatten toward that plane and reject road self hits. Reflected color streaking, sky fallback, AO-squared occlusion, soft clipping and constant road cover precede substitution. Car cover is hit-confidence-dependent.

Exposure, knee-masked bloom, lens dirt, radial sun shafts and optional HDR lift/gamma/gain/zone/toe/shoulder grading precede HDR ACES. LDR scenes instead clamp by white point. Common post-ACES grade then applies warm gain, contrast, vibrance/saturation, tint, split tone and black floor; flare, circular vignette, animated triangular dither and grain finish it. FXAA is the eight-spacing edge walk with .04/.125 flat-area rejection and .75 subpixel term. FXAA can fold the mirror inset using explicit analytic gradients; the separate inset path uses the same exposure/ACES/grade/dither helpers. Mirror hdronly treatment is selected after constructing the tone path. SGSR reconstructs from render to present size, uses emulated four-tap green gathers and clamps luminance corrections; optional fixed-target plain mode is bilinear. Debug blit exposes mono/gain.

## WGX shader strings and ABI

`wgsl-chunks.js` composes independent sky and surface noise families; the names/hash constants are intentionally different. Public leaves include hash/vnoise, tonemap, fullscreenTri, colourGradeLeaf and BRDF. The private material library is interpolated into LIT and references that shader's uniforms/textures. Shared `FRAME_U` also serves decals, preventing a copied layout drifting.

Exported byte contracts are FrameU 672, DrawU 144, Light 64 (MAX_LIGHTS 48), SkyU 240, ShadowU/ShadowModel 64 each, BlitU 96. Dynamic-offset alignment is a caller responsibility, with documented 256-byte draw/model stride. LIT frame binding group 0 includes lights, shadow compare resources, cube, legacy ssr placeholder, material arrays/scales, per-chunk storage and baked atlas/indirection. Group 1 is DrawU; group 2 is material/track storage. DrawU packs material scalars, lamp masks in two exactly representable 24-bit float integers, per-chunk offset/count/active and packDraw.

WGX recovers track coordinates through a 32×32×16 centerline LUT with magic 12345. The fixed sixteen-iteration search selects spatial neighbors constrained by along-lap distance, validates the final pair, faces the tangent toward +s and derives lateral x. Start/finish wrapping deliberately falls back to a coarse tangent-free circle rather than inventing a wrong tangent. The road's fragment stage uses reconstructed coordinates because measured Dawn interpolation shards markings; authored normal.w material IDs preserve MAT0 versus missing-ID distinction and car priority. Road classification and buryRibbon terrain discard are separate draw contracts. It flips backface normals except the road, whose authored upward normal is corrected independently.

Every derivative precedes varying control flow. Material pack taps are one dynamic-layer albedo/normal pair in uniform flow, under uniform packOn/packDraw gates; identity layers are sampled then ignored. Hoisted geometric/peel derivatives feed SAA after material classification. WGX uses finite-difference road normals in this source, whereas TLX defaults to analytic gradients. Material and car finish branches otherwise visibly mirror the same broad response families, without implying numerical equivalence.

Lighting/bake/wet/fog structure follows the TLX contracts, with WGX-specific storage and coordinate conventions. Per-chunk lamps use the draw's slice of absolute track-light indices and can compare mapped shadow via params10.x; global lights use frame slots and optional two-word mask rejection. Unlike TLX, lampContrib computes GGX terms even when NoLl is zero. Sun shadow coordinates already use WebGPU Z01, UV Y flips explicitly, Poisson 8/4 taps and blocker textureLoad. Cube reflection samples flip direction Y for stored face orientation. SSR is intentionally not consumed in LIT; its bound texture is retained as a placeholder ABI lane. Opaque scene alpha carries .35/.75/world eligibility and blend pipelines must preserve destination alpha for translucent draws.

SHADOW is vertex-only and chooses instance transforms through a zero-model sentinel. BLOCKER downsamples the whole source footprint with bounded 4×4 minimum loads, producing a blocker source without depth sampling through a regular sampler. BLIT tonemaps and optionally grades/dithers, including mirror/PiP horizontal flip and selected mip. SKY reconstructs view rays and implements gradients, weather/phase-aware cloud shading, twilight banks, lightning, day solar corona/disc, cloud-occluded stars/moon, city glow and dither. DEPTH_RESOLVE takes the minimum of all four MSAA samples, rather than the obsolete two-sample subset.

`wgsl-post.js` exports BloomDown 32 B, BloomUp 16, SSAO 176, Blur 16, Godray 288, Composite 256, FXAA 16, SGSR 16 and SSR 208. POST_VS produces a fullscreen triangle with texture-space Y-down UV. Depth helpers use clamped integer textureLoad and matrices remapped to WebGPU Z01; SSAO negates dpdy to retain the GL-facing normal. All post sampling under varying flow uses explicit LOD, except native gather. SGSR_GATHER rewrites the exact gatherGreen source block with textureGather's component-first call; the caller chooses it only when supported.

WGX post broadly follows the TLX pass families but is architecturally distinct: SSAO/godray are separate (no AO alpha fold), SSR is a separate half-resolution pass with full-resolution normal-depth stride, and composite bilinearly consumes its color/mix alpha in the same frame. SSR exposes road quality 24/16/8 and 4/2/1; its medium streak weights are .50/.25/.25, while TLX normalizes .30/.24/.24. WGX composite chromatic channels, speed blur and sharpen sample ordinary UV; TLX has haze-domain main chromatic sampling and a chromatic-aware caScene helper for blur/sharpen. WGX always calls ACES here; TLX gates by actual HDR scene format. These are source differences to retain in future investigations, not measured defects.
