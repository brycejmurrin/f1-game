## Cascade and loading

`css/tokens.css:13` declares `reset, base, components, hud, overlays`. Normal declarations in overlays outrank hud, which outranks components; specificity and source order decide within each layer. Every assigned file is layered; dialogs deliberately opens a second overlays block for VS Friend chrome. Font-face registration is layer-insensitive despite fonts-hud's hud wrapper.

`tools/manifest.cjs:486` owns the full CSS roster. Its `CSS_PRELOAD` and `CSS_DEFERRED` arrays at 504–523 govern title-blocking versus print-to-all activation. Of this assignment, components is title-blocking; the other 16 are deferred. The deferred list is not alphabetical: for example dialogs comes after experience/editor there, while appearance comes after data. Cross-file reasoning must use actual layer, specificity, and manifest order rather than this audit's alphabetical order.

The dialog reset in components is intentionally duplicated by dialog-platform: the former protects the period before deferred CSS activates. An author `display` can defeat the UA hidden/closed default, so explicit `[hidden]` and `:not([open])` guards are functional behavior throughout these files. Data Hub and Track Designer repeat closed-dialog guards in overlays because their layer would beat components.
