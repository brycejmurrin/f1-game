## Contracts proven by full reads

- `audit-diff.mjs` is browser-free: `rowFindings` normalizes hard findings into category/element/ancestor identity, `diffAudits` joins screen|viewport cells, and `runDiff` returns 1 only for added findings. Skipped cells remain unmeasured; absent baseline cells are out of scope. `formatDiff` ends with `= diff`.
- `audit-summary.mjs` accepts a directory or JSON file, defaults to `artifacts/layout-audit`, supports `--top` 1..200, substring screen/viewport filters, exact screen@viewport cells, and `--json`. Hard categories and x-overflow define bad cells; soft findings affect ordering. Readable reports return 0 even with findings; bad args/files return 2. Repeated cell heads collapse and output is bounded.
- `circuit-axis.mjs` parses absent `--circuits` as `[null]`, bare flag as five aspect-spread IDs, and explicit comma IDs without validating existence. `pickCircuit` clicks matching picker rows, returns false on no match, and always waits 250ms for a supplied ID. Thus requested cell identity alone does not prove the requested circuit was selected.
- `ui-scale-axis.mjs` parses only `--scale=`, accepts finite 40..200 percentages, uses null for shipping device defaults, and applies both real `__apex.uiScale`/`hudScale` store setters. Tags attach to viewport identity; circuit tags attach to screen identity.
- `menu-readiness.mjs` exports serializable predicates. Missing root/canvas returns true because callers must record missing roots separately. Infinite decorative animation does not block; finite running/pending animation does. Preview readiness requires useful buffer dimensions, a draw stamp or nonblank legacy canvas, and <3% box/buffer aspect difference. These comments are supported by the actual conditions; historical dated examples were not independently reproduced.
- `design-evidence.mjs` reads computed tokens from a chosen DOM root (512 custom properties, 30 representative visible controls), routes the local installed axe script temporarily and unroutes it in finally, then returns capped WCAG-tagged DOM evidence. It exports escaped HTML renderers, local raster validation and offline review building. `localImage` realpaths both root and file, rejects escaping/absolute inputs, allows PNG/JPEG/WebP up to 12MiB; reviews allow 1..40 shots and <=48MiB embedded strings including before images. Still images explicitly do not prove interaction/motion.
- `review-captures.mjs` owns no browser. It reads <=1MiB manifest, invokes screenshotReview, and restricts output to checkout artifacts/scratch including realpath parent and output-symlink checks. Errors set exitCode 1; help returns without work.
- `chunk-reach.cjs` uses track-build-vm and exposes `reach`, `probeCity`, `binChunks`, `aabbDist2`, CELL=72. Positional track/radii default vegas/900,400,300,200,150; samples 12 centerline stations. It bins triangle centroids into 72m cells, sphere-tests AABB distances and prints mean submitted chunks/indices. `probeCity` explicitly returns zero for skip-city. Count scope is geometry submission, not actual frustum, pixel cost or hardware timing.
- `chunk-share-census.mjs` owns a harness static server/browser, boots night/LOW, wraps LampChunks.resolve to retain distinct chunk-array/knob tables, sets perChunkLights=0.3, and prints empty/equal-adjacent/run counts. Browser close and harness shutdown are in finally. Dated measured percentages in comments are historical assertions, not this map’s verification.
- `gl-object-census.mjs` validates backend three/webgl2 and supports tracks, cycles, settle, JSON, quiet. Init scripts wrap WebGL2 create/delete APIs before application load, force TLX WebGL2, stub external race APIs, and use shared mem-census picker/readiness/GC helpers. Last two cycle live-count growth yields flat/grows report (not a nonzero finding exit). JSON includes summary/rows/errors. Browser and server cleanup occur in finally; top-level failure shuts harness down and exits 2.
- `mem-cycles-lib.mjs` exports preboot WebGPU object instrumentation and a pure plateau verdict. WeakMap plus FinalizationRegistry avoids retaining object handles; destroy immediately drops counters. Texture MB is an estimate (4 bytes/texel with mip/sample multiplier). At least six rows are required; second half paired means produce per-cycle rates, checked against 0.5MB or max(5 objects,1% total) defaults. Verdict reports growing/plateau; it is explicitly not a gate.
- `wgx-capture.mjs` and `wgx-lavapipe-probe.mjs` are synchronous child aliases with inherited stdio/status, not direct browser owners. Capture forwards webgpu, track, lite; silently consumes old --out/--frames values and warns on other flags.
