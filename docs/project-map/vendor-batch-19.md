This directly matches the `CP` backend-selection/`AP.init` path and its canvas/resource contracts. The fragment does not itself contain the final export statement, so the public-name association also relies on the constructor flag and local consumer usage.

Two local vendor extensions have concrete callers. `js/render/three/tlx-chunked.js:300–307` marks packed owned Uint16 indices with `__apexUint16Index`; `tlx.js:4310` and `:4950` also mark final indices. `XB` preserves only eligible scalar static nonnormalized noninterleaved Uint16 index data without restart value 65535; its shadow buffer pads and aligns later writes, and rejects changed format/length/restart or invalid ranges. `js/render/three/tlx-post.js:1130–1154` sets/clears render-target discard hints around selected final passes; `tlx-shadow.js:126` sets the color discard flag. `AP.beginRender` consumes those exact target fields to choose GPU attachment store operations. This establishes static wiring, not measured memory/performance benefit.

The WGSL generator, binding layout builder, attribute formatter and pipeline validation path are backend infrastructure used transitively by local node materials and WebGPU draws. The presence of compute, storage textures, direct pipeline, readback and array-camera APIs in the vendor fragment does not establish that every API is exercised by the game. The inspected local renderer explicitly disables multiview.
