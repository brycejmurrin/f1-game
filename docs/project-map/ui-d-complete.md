Phone wiring lazy-loads networking, guards stale loads with generation IDs, adapts native share URLs while preserving fragments, drives dashboard flags, restores the previous camera only if the user stayed on VISOR, and exposes same-code recovery/new-code controls. Lifecycle flushes ghosts/storage before updates; hidden/pagehide disarm probes, hidden racing pauses, wake locks reacquire on return, and hidden friend races pump networking every 500 ms. Blur pause is delayed 250 ms and excludes automation/network races; audio interruption also excludes network races. First gesture is shared one-shot activation detection across pointer/touch/key/click; Escape and touch pointerdown do not spend it.
