## Ownership and contracts

- **key-binds.js:** `KeyBinds.create(G)` owns keyboard/controller setting rows, binding capture, Help synchronization, controller labels, stick calibration, sequential wheel axis capture and an opt-in live preview. Input owns the binding maps and device selection; `G.store` persists keys/pad/padAxes/padRest/padLabels. Capture is trusted-key-only, window capture phase, IME-safe; one section is armed at once. `disarmAll` cancels calibration, timers, preview and wheel capture when SettingsNav leaves Controls or callers close settings. Return contract is `{render, disarmAll}`. Global listeners are session lifetime; wheel/calibration owners prevent commits to a replacement device.
- **layers.js:** `window.UiLayers` owns layer IDs, driving gating (`anyOpen`), navigation gating including title/rotate blocker (`navOpen`), and topmost focus layer (`top`). Native modal membership outranks z-index; modal opening serial breaks modal ties, DOM order breaks ordinary z-index ties. It wraps native showModal to stamp ordering and includes dynamic `:modal` dialogs beyond the ID list. Three memoized answers share synchronous MutationObserver invalidation and a 250 ms safety expiry. Geometry is retained for CSS-gated/zero-width wrappers; game state comes only from injected `setRaceGetter`. Public API: LAYER_IDS, top, anyOpen, navOpen, shown, inRace, setRaceGetter, trackDialog.
- **loading-screen.js:** `LoadingScreen.create(hooks)` owns `#loading`, card facts/map/grid, flyby timer and skip input, announcer/radio arbitration and geometry persistence. It is a phase machine: prep/garage/build → run or card → handoff; hold is editor preview, busy is general wait, and lowerWaitPlate clears wait phases once racing. Only run/card report `active()`, so visibility and canvas ownership differ intentionally. Fresh presses obey 400 ms grace; held pad buttons/repeated keys cannot skip, and `fire` clears the callback before invoking it. stop cancels voice, radio, skip handlers and polling. The pure exported helpers cover budget/streak, real-race facts, grid layout/colors, geometry normalization and material-pack readiness. Main default flyby 20 s; habitual-short 10 s; maximum read 60 s; fallback card 700 ms. Geometry uses ldCard, streak uses flySkips. Static slowNotice/failed serve lazy bundle loading; failed resolves retry/back while leaving card ownership to its caller.
- **menu-nav.js:** self-starting `window.MenuNav` owns wheel redirection, spatial arrow navigation and pane-scoped paging; it consumes UiLayers for authority and ScrollFade/CssZoom for paint and coordinates. Native scroll regions retain their wheel even at an edge; horizontal strips translate vertical wheel. Arrow movement respects widget-owned axes, trusted editing keys versus synthetic pad directions, roving listboxes, wrapped chip groups, tab rails and free-camera/title-layout exclusions. Measurement cache exists only for one key press and is released in finally. Public helpers expose activeLayer, nearestPane, event handlers, FOCUSABLE, step, pickSideways, items, currentItem, ownsArrows.
- **modal.js:** self-starting `window.TopModal` mirrors hidden to dialog showModal/close, routes Escape through each screen's own door, maintains title inert/aria-hidden isolation, and contains focus. Native cancel/close recovery protects gates and ignores stale queued close events after reopening. Non-dialog layers get opener/last-focus memory and explicit boundary Tab wrapping. `keepFocus(scope,rebuild)` preserves slots across destructive DOM rebuilding. Public scan/wire and scanLayers/wireLayer permit dynamically built screens to join; it does not observe every new subtree automatically. UiLayers is authoritative and MenuNav supplies shared focus rules after loading.
- **onboard.js:** `Onboard.create(G)` produces tick/reset/state/MARKS. It reads car and BrakeCue reports without mutating driving state, offers prioritized brake/overtake/aero/harvest prompts, observes race starts, enforces cooldown/retry and persists bitmask/race count. Announce rejection never spends a mark. Current input maps and active device determine copy. A module-level refresher points to the newest instance's reset. `harvestClipCue` is exported pure report logic; mark constants are exported too.
- **pause-opts.js:** self-wiring `PauseOpts` depends on GameStore at evaluation; SettingRow and ScreenLooks are late-bound. It validates four persisted preferences and stamps only nondefault html data attributes, mounts settings rows, composes shipped status with ScreenLooks, and peeks the pause card after changes. Capture click on quit/restart consumes the first press and permits a second within 5 s; disabled buttons never arm, hide/off clears state. It also paints loaded-build metadata. Exports preference constants/readers/setters, apply/initUI/wireRows, and confirmation controls.
- **photo-studio.js:** `PhotoStudio.create(G,deps)` constructs its controls inside the shell root and returns open/close/capture/state/contactSheet/album/background/setBackground/exportPhoto/savePhoto/hasCar, or null if absent. It borrows FreeCam or garage camera, optionally a temporary Home-track car, and restores camera/conditions/lighting at close. Garage looks intentionally persist through garage setters. Circuit lighting clones `_ltStore`, restores the exact original reference, and uses injected LightStore setters without renderer-recovery side effects.
