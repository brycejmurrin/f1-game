## Ownership and runtime boundaries

These directories do not implement a second game. Desktop and mobile package the root static runtime through `tools/desktop/stage.mjs`; its allow-list, minification and Pages stamping are external dependencies. Runtime behavior still belongs to the owners of `js/`, `css/`, `index.html`, assets and vendor code.

Desktop owns the Electron process and fixed `app://apex/` origin. `main.js` takes a single-instance lock, restores/focuses the existing window, registers the scheme before readiness, serves development `dist-site` or packaged `resources/site`, and creates an isolated, sandboxed renderer without Node integration. A second instance does not create another normal game window. Renderer crashes/unresponsiveness offer an explicit reopen/quit decision; reopening preserves user data and replaces one window. F11 toggles fullscreen. External HTTP(S) links open through the OS; other windows and navigation away from the app origin are denied. Soft GL and no-sandbox require explicit environment flags. The smoke path has an independent 60-second deadline, polls document/native/origin readiness and returns JSON plus exit status; this is shell evidence, not proof of a running race.

`app-protocol.js` owns disk HTTP-like behavior: fixed host, realpath root containment including symlinks, extension MIME lookup, full streams with Accept-Ranges, single/suffix/open-ended byte ranges with 206, unsatisfiable 416, missing/non-file 404 and unsafe target 403. Malformed range shapes fall back to full response. Exceptions become 500. Its path helper comment says null for missing files, but nonexistent safe paths are deliberately returned and become 404 in the handler. It does not implement an ordinary web server or multiplayer transport.

`preload.js` exposes only frozen detection/platform/runtime-version data through contextBridge. `lib/permissions.cjs` grants fullscreen, keyboardLock, pointerLock, screen-wake-lock, sanitized clipboard writes and video-only media to the app origin and rejects foreign embedding origins; microphone and unlisted permission requests fail. `identity.cjs` freezes appId/productName plus intended scheme/host; actual protocol constants are separately declared in `app-protocol.js`. Altering identity/origin changes persistence boundaries. `site.cjs` chooses explicit APEX_SITE_DIR, a current-HEAD dist-site, or current-HEAD artifacts/site; stale dist-site is an error. Explicit override is caller-owned, and assertStagedSite validates index presence and positive version build. `version.cjs` validates MAJOR.MINOR and positive integer build to produce desktop semver.

Android owns a Capacitor 8 WebView shell at `https://localhost`, app id `io.github.brycejmurrin.apex26`, and native file/share plugins. `lib/identity.json`, Capacitor config, Gradle applicationId/namespace and string resources must stay consistent. `server.url` is absent; mixed content/debugging are disabled; minimum WebView is 100. `MainActivity` sets keep-screen-on and transient immersive bars while delegating bridge lifetime to BridgeActivity. The manifest allows all orientations with fullSensor, declares vibration/internet/camera, makes camera/autofocus/touch/gamepad optional, forbids cleartext traffic and backup, and provides cache/external FileProvider paths for sharing. Fullscreen CSS/system-bar inset behavior remains jointly owned by web UI and Capacitor's SystemBars config.

`mobile/scripts/sync-web.mjs` reuses the common stage pipeline. It reuses artifacts/site or _site only if stamped at HEAD and the working tree, including untracked files, is clean. Explicit --src checks index presence and is caller-owned. Fresh production stage is stamped; remaining ?v=dev tags are rejected without --dev. Default copy refuses overlapping real source/destination, copies to a temporary sibling before replacing www, then optionally runs cap sync android. Custom --out requires --skip-sync, an existing parent and a NEW destination; it reserves that destination without deleting caller files. A copy failure can leave a new isolated output partially populated; the existing normal www is preserved until copy completes. Exports offer seams for root unit tests.

The optional Worker owns signalling mailbox storage only. The outer handler accepts OPTIONS without allocation, refuses methods except GET/POST before rate accounting or Durable Object naming, returns 426 on obsolete /r/ paths, and routes only lowercase 64-hex `/v3/r/<id>/<offer|answer>`. It names ROOM objects `v3:<opaque-id>`, passes the slot through a query parameter, and exposes protocol header 3 with CORS and no-store JSON. In-isolate fixed-window per-IP limits are 20 writes/180 reads per minute, with a 4,096-entry recency-evicted map; these are explicitly not global enforcement.

Room GET checks expiration immediately. POST bounds both declared and streamed body bytes (12,800), bounds sealed payload (12,288), validates v2 base64url shape and optional owner capability grammar, then updates slot and earliest-expiry alarm in one storage transaction. A live offer can be replaced only by its same owner capability; answers are replaceable without that offer restriction. Each slot has its own 120-second TTL. Alarm transaction deletes expired records and reschedules surviving records, so later answers cannot extend expired offers. Platform-delayed alarms can retain bytes physically after logical expiry. No token, encryption key, SDP decryption, account, gameplay forwarding or analytics is implemented here.

## Dependency and release contract

- Desktop npm is independent of root npm: Electron 44.4.5, electron-builder 26.15.3, Playwright/test 1.63.0 and fuses 1.8.0 are exact pins in both manifest and v3 lock. The lock records the entire transitive registry/integrity/license/engine graph, including optional/peer branches; it is not app runtime source. Electron's lock entry requires Node >=22.12.0, narrower than the README's >=22 shorthand.
- Desktop scripts stage before version synchronization, then prebuild validates stage, generates notices from explicit root asset/vendor license inputs and stamps package version. Setting APEX_APP_VERSION inside the set-version child cannot export an environment variable to its parent; the package.json write is the durable version output. Builder also accepts a caller-supplied APEX_APP_VERSION for extraMetadata. Compatibility sync-version.mjs forwards argv/status to the canonical script.
- Builder packs main/preload/protocol/lib/package metadata into asar, puts the staged site and notices outside it, and freezes persistence metadata. Release fuses disable RunAsNode, NodeOptions, inspect CLI and file-protocol privileges; cookie encryption and only-load-asar are enabled. pack:test explicitly enables inspect for Playwright. Windows uses x64 NSIS preserving app data; mac emits arm64/x64 dmg+zip with unsigned identity and future signing entitlements; Linux emits AppImage+deb. Publishing is null. No auto-update service is implemented.
- Desktop icon generation depends on root sharp and root icons/icon-512.png. 1024 art is explicitly a labelled upscale placeholder. Notices are generated/ignored, and fail if required license inputs are absent. Unpacked binary resolution handles host Linux/Windows/mac layouts and refuses missing files; read-fuses calls the installed fuses CLI against the binary or mac app bundle.
- `.github/workflows/desktop.yml` is an external consumer: ready packaging PRs run Ubuntu pack:test; dispatch runs all three OS smoke lanes; desktop-v tags/dispatch run installer release. It does not participate in ordinary game-only PRs or Pages release pushes. This read established routing/configuration only, not a green current CI run.
- Packaged tests use one serial worker, launch the unpacked binary, require inspect enabled, sanitize inherited ELECTRON_RUN_AS_NODE/NODE_OPTIONS, opt into test soft GL/no-sandbox, check native origin/version, #game, actual PerfSpans frames and serious page errors, exercise main-process fullscreen and offline shell reload. Collected console errors are not asserted. Software WebGL context existence is tested, not physical GPU performance.
- Mobile npm is independently locked: android/core/CLI 8.5.2, Filesystem 8.1.3, Share 8.0.2. Generated capacitor.settings.gradle and capacitor.build.gradle wire node_modules projects and Java 21. Root Gradle pins Android plugin 8.13.0/google-services 4.4.4; wrapper distribution is Gradle 8.14.3-all with URL validation and 10-second download timeout. Variables set min SDK 24 and compile/target 36 plus pinned AndroidX/test/Cordova versions. app Gradle consumes env/property version inputs and optional environment signing credentials; no keystore is tracked. Release minification is off, so commented ProGuard examples currently do not add shrinker behavior.
- Android scaffolding includes an instrumentation package-id assertion and a local arithmetic template test; these are not gameplay/native behavior coverage. Android generated public assets/config/Gradle outputs, www, node_modules, local SDK paths and keystores are ignored. Config and resources are committed; re-adding Android would overwrite custom native behavior.
- Worker deployment is independent (`wrangler.toml`, compatibility 2025-04-01, ROOM binding, v1 SQLite migration); there is no worker package/lock pin for the documented npx wrangler command. No cloud deployment was attempted or verified.
