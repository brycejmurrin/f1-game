## OpenF1 structural validation

The complete JSON parses without malformed/nonfinite values. It has22 driver records,983 laps,58 stints,36 pits,141 race-control events,14 weather rows,22 results,22 initial positions,160 overtakes and31 radio records. The location excerpt contains179 three-number rows in decimetres, with strictly increasing time values. Every non-null field ending in driver_number in these record arrays resolves to the fixture's driver roster. These are integrity checks across all rows; they do not establish sporting accuracy, complete upstream endpoint coverage, external recording availability or rendered replay fidelity.

LSP resolves DataRealRace to js/data/real-race-tab.js, including build at154, gridFor136, cautionsFor102, packTrace573 and trace-fetch/cache APIs. Its first30-row outline explicitly has further exports and is not claimed exhaustive. RealRace resolves to js/race/real-race.js with pace/grid/field/launch/replay responsibilities. Semantic references for RealRace.launch returned four references across the data-tab and runtime modules. Shared domain reports provide complete production-source reads; this fixture pass checks identity, shape and usage boundaries without rerunning simulation.
