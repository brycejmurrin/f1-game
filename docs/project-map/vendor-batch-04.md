## Bundle/API and local consumer context

This interval is the embedded Ace editor infrastructure inside Spector, not the outer SPECTOR capture API or WebGL interception implementation. Internal module exports above feed other Ace factories through `require`; their presence does not establish a standalone globally exposed Ace API. The surrounding UMD/global wiring is outside this interval.

For local context, fully read `js/agent/apex-gpu-capture.js`. `ApexGpuCapture` lazily injects `vendor/gpu-capture/spector.bundle.js` only when explicitly enabled by query/storage/API (off by default), reads `window["SPECTOR"]`, constructs `Spector`, optionally calls `spyCanvases`, and captures with `captureCanvas(canvas,true)` or fallback `captureNextFrame`. `onCapture`/`onError` observers settle compact JSON capture summaries; timeout is 8000 ms. It never directly calls the Ace modules mapped here. Its public wrapper returns api/boot/wanted/status/hooks/disable/enable, and hooks exposes `gpuCapture`. This ties bundle loading to the application without claiming these editor fragments execute on every capture.
