### Portable hardware diagnostics and their report gate

- `gpu-game-check.mjs` (1–1734) is a top-level CLI, including top-level server/browser launch; importing it executes the workflow. `--help` exits before either. It uses Playwright directly rather than the harness, resolves ROOT with fileURLToPath for Windows, serves fixed MIME types over loopback, supports fixed port plus persistent profile, and defaults to Montreal/three/WebGPU/15 beats/API entry. Camera ID or A>B and entry api/menu/menu-full are validated by census-entry helpers; memory cycles clamp 0..24. Argument getters use spaced values; this is not the strict shared flag parser. Extra localStorage pairs apply after backend defaults. No hardware classification is required by this producer itself: adapter details are evidence for the downstream census gate.
- Before scripts boot it installs bounded recorders: 40,000 callbacks/game-frame timestamps, 4,000 per-frame signatures/work records and long tasks, 64 large rAF gaps, 200 stack samples, 1,500 LoAF entries with eight scripts each. WebGPU/GL upload wrappers preserve original calls, count/timestamp work and carry bytes; texture image/PBO estimates assume four bytes per texel while typed-array lengths are exact. The raw-rAF controller uses probe/scan/setInput, braking envelope and pure pursuit, and its stop clears input and parks at 0.1. LoopHealth distinguishes finished game frames from multiple rAF callbacks.
- API entry calls race then track-ready; menu entry clicks title/select/settings, optionally changes time, records prep timeline and garage prewarm, and starts even if prep timeout expires (recorded as unready). menu-full adds fullIntro. The race gate waits actual race/no pending warm and records whether warm was requested. Race-entry profile clocks, long tasks, LoAFs, build CPU phases and warm stages are joined separately from the driven window. `--no-drive` leaves parked evidence; a missing driver is named. Two consecutive 8s missed beats stop sampling; beats drain GL errors once each unless per-present drain was requested. CPU sampling, pass composition, gaps, spike work and depth-discard deltas share this window; later feature A/B is excluded by disarm.
- Optional pack mode fixes tier/resolution, freezes field and compares near/far 6s rAF samples. Occlusion/multiDraw A/B first skip unsupported backends; otherwise pin clock/freeze sim, capture off/off2/on plus fresh presentation receipts, compare same-state noise and feature image differences, then interleave 20 off/on rounds for timer medians. These are diagnostic rows rather than local gates. Missing screenshots, timers and hooks remain missing/error. The later moving occlusion probe, A-B-A track switches and race/quit memory cycles have independent bounded reads.
- Checkpoint JSON writes after phases are best-effort; final JSON write is not. `bounded()` converts a timeout/error into `{error}` rather than failing the run; it races but does not cancel the underlying page operation. Consequently `ok:true`/phase done means orchestration reached the end, not all reads were valid or the race reached. gfxReadFailed/overlayReadFailed/frameReadFailed name major gaps; `census-verdict` supplies actual renderer gates. A single screenshot's brightness is report-only. Finally retains filtered console and ROOT, races browser close against20s, closes server and explicitly exits by out.ok.
