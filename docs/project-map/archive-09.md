S09-07 is primarily hypotheses. S09-08–10 and S09-14–18 preserve negative findings so later work can avoid repeating disproved micro-optimizations. - **Keep measurement identity explicit.** S09-06, S09-24–26 distinguish source SHA, public Pages SHA, built track/grid, pre-construction seed, moving-field assertion, warm-up, drawing/submission/completion and visible presentation. Rounded hook hashes are weaker than raw IEEE/Object.is parity. S09-25 reports useful workload CPU reductions with variability; S09-26 explicitly rejects a performance conclusion from overlapping, oppositely moving comparisons.
- **Preserve per-pass resource ownership.** S09-15–18 separate main/mirror instance buffers and ring slots; pooled descriptor aliasing is a rejected optimization. S09-21 scopes shadow caster roots by pass. S09-23 skips resources excluded by boot-constant lite policy while preserving placeholder bindings and desktop SSR. S09-24 requires last-owner shared-binding eviction and exactly-once exceptional capture staging destruction.
- **Prove behavior while eliminating work.** S09-06 records quit FX cleanup, cancellation of scheduled cheer ramps before silence, incident handback before field replacement, exact prop bytes and raw simulation parity. S09-20 compares against current DOM text/disabled values so external changes repair naturally. S09-22 preserves focus, Undo announcements and identical HUD geometry. S09-24 separates retained heap, requested graphics storage, native driver residency and measurement completeness. A budget pass does not prove leak freedom.
