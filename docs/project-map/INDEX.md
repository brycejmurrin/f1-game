## Evidence usage

Per-family batch manifests retain exact half-open byte ranges and source identities. Companion JSON files hold large case ledgers, raw historical paths, chunk hashes and identity relationships. Full-source assertions rely on the readers' recorded untruncated tool-return attestations; the independent audit checks recoverable identities, bounds, rosters and unions. LSP fallbacks, unresolved dynamic properties, mocked tests and historical measurements keep their stated limits.
