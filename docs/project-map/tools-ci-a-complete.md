assert-audit: Espree scans top-level spec-directory files, follows same-file named helpers to a fixpoint, recognises test import aliases, grades asserting/implicit/vacuous and empty catches. CLI is a report, not a failure gate; ratchets.mjs imports audit for enforcement. Static presence does not prove assertions execute.

### `tools/ci/base-green.sh`

base-green: SHA + GITHUB_REPOSITORY → green/red/unknown. Only completed ci.yml/pages.yml success permits diff narrowing. Bounded first 30 run records; unknown is fail-safe at ci.yml callers. GET through gh.

### `tools/ci/base-verdict.sh`

base-verdict: strict ancestor of requested head among latest 50 completed deploy runs → notice and optional summary, failed job names from first 100 jobs. Advisory; full history needed. Does not gate or prove ownership of individual test failures.

### `tools/ci/behind-ship.mjs`

behind-ship: resolves head/ship refs and rev-list count; warns above 10, default origin deploy. Always exits0 after ordinary measure failures; --json suppresses human annotation output. No fetching.

### `tools/ci/branch-audit.mjs`

branch-audit: remote refs + saved PR/run JSON → ancestor/pr-head/absorbed/presence/PR/CI verdicts. Default survey requires --prs, no PR or closed-unmerged quiet48h; --all widens.
