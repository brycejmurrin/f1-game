## Diagnostic and historical contracts

The submission metrics installer exports a browser-injected function that creates a global API once and wraps each renderer once. start resets counters, rows and render-target identities. Wrapped render calls use a depth guard, retain the original call/exception behavior, count failed calls in finally, and aggregate successful draw/triangle deltas plus synchronous wall duration per target. A named output target or direct Scene-to-canvas call counts as a main render. stop returns per-render/per-main statistics and quantiles. The wrapper persists; it has no detach path, and duration arrays grow with the measurement window. Its comments correctly distinguish synchronous submission wall time from GPU time, asynchronous software readback and pure JS self time. A nonzero main-render count, comparable warm windows and dimensions remain caller responsibilities.

The livery census summary CLI reads an optional positional JSON filename, groups nonmissing edits by kind and writes Markdown to stdout. It reports median next-frame delay, worst frame, accumulated long-task duration and a whitelist of allocation/build/shader/texture counters, plus missing edits and page errors. Its consumer is the optional GPU census workflow, whose command appends stdout to the job summary and masks failures. The helper itself can throw on file, JSON or schema errors; its “never fails the job” comment describes the caller's protection, not an internal guarantee.

The offline image comparator pairs backend PNGs, skips incomplete pairs and crops both to overlapping dimensions. It computes percent pixels with summed absolute RGB difference above 30, mean absolute channel difference, luminance and the strongest one-third-frame crop at one-twelfth-frame strides. It writes paired thumbnails, native crops, heat maps and JSON for the historical gallery builder. Small images can create a zero stride. Pairing by filename and shared overlap does not prove matched cameras or moments.

The dated facts record is hand assembled: memory rows, GPU results, captions, limitations and a renderer recommendation. Memory is heap plus ArrayBuffer backing stores after forced GC and excludes GPU memory. The GPU numbers describe a CI Mac with forced phone caps; local software frame rates are explicitly rejected as phone-performance evidence. Raw pair metrics retain grid and medium-helmet mismatches that the narrative and gallery selection exclude. Low still receipts record differing mirror readiness/draw states; later reshoot claims cannot be inferred from those receipts alone. The four local performance files record tiny software-rendered frame samples with and without CPU throttling, governor/environment receipts and empty recorded error arrays. Empty error arrays are historical observations, not present test passes. The assigned census suffix contains only the warning tail and browser/page closure flags.
