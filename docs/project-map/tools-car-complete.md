## Ownership and direction of data

The authoritative inputs are the runtime registries and builders: `js/data/teams.js`, `js/car/parts.js`, livery/crest modules, `js/car/helmets.js`, geometry/material/shading modules, `Car3D`, and `CarMesh`. The tools load those sources into Node VM lexical contexts and retrieve bindings by evaluating their identifier; a top-level `const` IIFE is not a property of the sandbox object. A second path boots the generated isolated `tools/carview.html` and drives `CARVIEW`; `carshot` and `career-economy` boot the game and drive `__apex`.

Most outputs are disposable reports/images under `artifacts/` or `scratch/`. Two authoring tools can write runtime source: `trace-logo --write` replaces `js/car/crest-paths.js`; Blender's `author-crew-motion.py --write-runtime` replaces only the marker-delimited sampled motion block in `js/garage/crew-motion.js`. Neither path was invoked. The isolated viewer is generated: change its source/generator, not `tools/carview.html` (AGENTS rule 11). The CLI documentation index `tools/README.md` is generated as well.

The offline tools are libraries as well as commands; importing `parts-sweep`, `crest-sweep`, `fit-geom`, `fit-checks`, `car-fit-audit`, `parts-ladder`, `flank-occlusion`, `spine-station`, `tri-census`, and `trace-logo` exposes their functions without invoking their guarded CLI main. Conversely `helmet-sheet`, `helmet-trace`, `logo-authored-sweep`, browser capture scripts and the Python script execute their workflow at top level; do not import them as passive libraries. `livery-contrast` also initializes a crest VM at module import, although its CLI sweep is guarded.

## Geometry, value, and cockpit audit contracts

`tools/car/parts-sweep.mjs` owns the visual-distinctness measurement library. `loadParts(:96)` loads canonical files, optionally CarShade (`shade=false` default). `assertFlapSig(:133)` source-scans hashed vs solver-read recipe fields to reject cache aliasing. `catalogRows(:171)` measures SIGNATURE/STYLE against their `equivalent`, otherwise category default, on an eligible team's actual setup; `assertResolves(:199)` prevents fallback IDs from silently masquerading as requested parts. `buildCar(:244)` memoizes by team/pose/setup, builds measured complete mesh (including wheels and active flaps), while open-aero pose reproduces flap rotation. `buildTiers(:266)` enables one-key attribution.

`compare(:504)` computes capped (0.30m) nearest-triangle displacements through 40mm CSR spatial cells, two-direction centroid moved area, A-side vertex maxima, bbox changes, palette/material histogram transport, trusted-nearby color diagnostic, section ownership and aligned-index displacement. Visibility uses fourteen 192px orthographic rasters with 20mm slack and thin-triangle centroid fallback. `classify(:668)` emits BASELINE/BROKEN/SLIDE/INVISIBLE/COLOUR-ONLY/INTERNAL/WEAK/OK. Frozen thresholds: 5mm invisible, 20mm weak, 3mm moved-area floor, .010m² meaningful moved area, .002m² invisible area, .05m² color/material transport, slide ratio 3. It is a sampled geometric/visibility proxy; it does not prove pixels read well under lighting or a particular camera.

`sweep(:700)` catches per-row exceptions as BROKEN and considers open aero when its dHaus improves the result. `attribute(:749)` changes one differing resolved recipe key/tier at a time. `clampScan(:790)` tests authored key ranges in the richest host recipe to keep dependent gates open; runtime-only keys are diagnostic. `sweepParallel(:855)` workers each own VM/cache; default up to four, costly aero/categories first, reassembles catalog order, 3GB old-generation limit per worker. CLI accepts cats/team/only/workers in equals form plus modes. Normal tabular path sets exit 1 for INVISIBLE/BROKEN; `--json`, attribute, calibration and clamp-scan return earlier, so do not treat their zero status as a gate (`:944-997`).

`tools/car/lib/fit-geom.mjs` is the independent fit core. `loadCar(:81)` can load another root and skips absent files for old refs. `buildCar(:105)` uses factory preset plus overlay, far-apart red/blue colors and optional body look, measured complete mesh. `sectionsOf(:119)` supports explicit from/to or older sequential vertex counts; tail is aeroFlaps. `analyse(:136)` emits triangle positions/areas/normals/sections, per-section 0.05mm-quantized welded IDs, connected pieces, closedness/nonmanifold/boundary edges, visibility and 40mm CSR query grid. Visibility is fourteen 448px views, 6mm depth slack, bbox framing snapped to 5cm. `eachNear(:236)` deduplicates triangle visits with epoch stamps and supports callback false; `closestOnTri(:253)` gives nearest point, distance and region.

`tools/car/lib/fit-checks.mjs` consumes that analysis, returns rows `{check,a,b,value,unit,fail,where,note,count}`. GAP (`:33`) unions contacting pieces within 3mm plus up to four passes of embedded closed-piece joins; biggest chassis piece anchors main cluster, other visible clusters report nearest external surface up to 250mm. PENETRATION (`:153`) uses local nearest-face summed-normal sign inside a closed foreign piece within 60mm and requires target face visibility; general failure >20mm. Tyres (`:206-254`) instead fit analytic annuli from material IDs 22/33; nonwheel vertices inside their width/radius span fail >3mm. ZFIGHT (`:259`) takes four samples per visible face, agreeing normals >=.999, distance <=.25mm, no shared welded vertices and differing look; accumulates quarter smaller-face area with pair dedup, fails above 1cm². OPEN (`:308`) sums visible single-use welded edge lengths unless midpoint is sealed within 3mm, warns above 50mm, records nonmanifold count. These are local/finite samples, not general solid-intersection proofs; tyres are approximated annuli; material IDs and section conventions are explicit maintenance couplings.

`tools/car/car-fit-audit.mjs:47-217` orchestrates all checks, merges per-section-pair rows (count, worst location/value, n/nFail), factory/style/body jobs, summaries and baseline comparison. `--all-styles` covers STYLE/PREVIEW only and applies availability gates. `--base` archives **js only** to `artifacts/car-fit-audit/base-<sha>` and rebuilds using current tool code. `--write-baseline` writes before comparison; saved baseline path is caller-chosen. Compare mutates head rows by team/style/check/a/b; missing style falls back to base factory. NEW requires above limit plus NOISE (GAP/PENETRATION 1mm, ZFIGHT .5cm², OPEN 10mm); WORSE requires own slack or increased failure instances/count (>25%+2). Absolute run gates FAIL but OPEN is WARN; comparison gates NEW/WORSE including OPEN. JSON retains exit behavior. Explicit unknown styles in a base lacking them throw during plan rather than silently omit (`:91`); the factory fallback applies when the comparison actually lacks a built style.

`tools/car/parts-ladder.mjs:57-237` separates economics from appearance. It collapses exact cost/four-stat clones and optional team availability; strict domination is exact cheaper/equal plus no worse speed/accel/cornering/braking and some improvement. `liveSet` samples 20,000 deterministic positive weight vectors over log stat multipliers, computing exact upper cost/value hull for each (lambda is not sampled). Tyre life is deliberately excluded because session race distance changes its value. Reports shown/live/dead/traps/flat axes. Normal console mode exits 1 for paid dominated rows; JSON returns before that gate. Unknown team becomes null/all availability, unknown category can yield empty output; CLI has no strict unknown-flag validation.

`tools/car/cockpit-pale-sweep.mjs:26-149` loads the real cockpit with Parts/Liveries, excludes wheels/driver, includes halo. Eye `[0,.82,-.20]`, near cutoff .30m; nearest Möller–Trumbore ray hit uses first vertex color. Pale means all channels >.45 with spread <.35. Samples yaw/pitch every 1.5°, vertical FOV 78 and aspect 2.2 by default; reports RGB buckets with hit count, range, yaw/pitch. CLI uses default parts plus first team livery and validates team IDs; any pale hit exits 1. Sampling uses `hfov=vfov*aspect`, a proxy rather than tangent-derived perspective horizontal FOV. Loader reads paths relative to cwd, unlike most root-resolved loaders.

`tools/car/tri-census.mjs:38-105` loads another optional root with localStorage smooth toggle and counts player(noWheels), field(noWheels+field), caster(silhouette), flap(complete minus plain) meshes for each body, optionally each aero STYLE and flat shading. Shared far body is a separate row using first team's factory setup, grey/noDriver/noWheels/silhouette/field/smooth false. Default team ferrari; console/JSON only, no pass/fail budget gate. Its consumers impose budgets. Counts do not measure frame time, GPU behavior, memory or actual draw calls.

## Paint, marks, and placement contracts

`tools/car/crest-sweep.mjs:34-431` provides `RecCtx` through `loadCrests`, plus cssOf/replay/paintAt/paintStackAt. Recorder flattens curves to 16 segments (arcs 32), tracks paint order, affine path transforms, clip intersections, fills/strokes/text rectangles and separate image shadow calls. Replay runs real drawCrest and reports fit-normalized bbox/minstroke/colors/fonts, coverage at arbitrary resolution with optional excluded backing style. `paintAt` returns top declared style; `paintStackAt` composites parseable rgba paint over supplied RGB background. CLI all or named teams, cover+badge, 430/40px, flags SMALL/THIN/BLEED/MIP/BLOB/FAINT; flags are reporting only, no nonzero failure status. Unit consumers assert requirements.

Recorder limits are material: text is approximate `.6*fontSize*length` by `.72*fontSize` rectangles; strokeText/clearRect/image pixels are not drawn; globalAlpha/lineCap/lineJoin are ignored, compositing only recorded, gradient handling partial, arcTo approximated. It supports this atlas's tested subset, not the Canvas2D specification or antialiasing/real font rasterization. `paintStackAt` handles alpha embedded in rgba strings only. Loaded-image crests cannot be faithfully measured by recorded paths.

`tools/car/livery-contrast.mjs:38-148` uses RecCtx to run real high-resolution atlas build. `sweepAtlas` assigns top paint owners on 24x24 region grids; owners >=15% area, alpha>=.5, opaque underlying paint alpha>=.9, skips exact same-geometry/style redraws, reports worst contrast under 2:1. `sweepAll` covers team × spineLogo × spineSide in crest/spineSide/spineSideL/tail/fin regions. CLI JSON and text both fail on hits. It deliberately measures broad flat paint, not glyph readability; unknown `--team` filters to zero teams with no error.

`tools/car/logo-authored-sweep.mjs:19-80` tests markPalette across every team/livery × eight selected colors × cover/badge: logo must reach mark; logo2 can reach plate/alt/part/outline. No args accepted. Prints JSON kept/dropped, by-surface, detail, Audi and worst-team summaries; no nonzero status for dropped colors. Palette selection is evidence about palette transport, not final textured pixels.

`tools/car/spine-station.mjs:55-246` samples atlas region over actual cover color (not white), compares each side design to same crown with side none, threshold summed channel delta .02. Returns ink footprint u/v extents/midpoint/share and optional hidden fraction over changed ink. u runs front→rear by reversing canvas x on right flank, v crease→sidepod. Measures crown mark separately versus bare cover while filtering translucent ops. `sweep` supports explicit livery/field overrides for callers; CLI offers team/all/logo/side/grid/scale/PNG directory/JSON and `--occlude`. Optional occlusion loads real mesh map at grid96 per team. PNGs are nearest upscale previews; JSON output is one object per team (not an array). No placement acceptance gate.

`tools/car/flank-occlusion.mjs:35-237` builds body plus four wheel layers at copied runtime anchors, obtains spineSide quad/UVs from actual decal mesh, bilinearly maps front-based u/v to car-space skin. Perspective camera uses radians az/el, 36° FOV, 16:9 default aspect; SIDE defaults azπ/2/el.10/dist4.6/ctr `[0,.45,.245]`. Projects/buckets triangles in .02 image-space cells, compares sample depth with 50mm slack to avoid skin self-occlusion. `occlusionMap` returns cols/rows/byte mask/eye; `hiddenIn` returns sampled hidden share. CLI outputs whole/bands/ascii or JSON, accepts shared strict flag names, no visibility gate. Unknown team silently falls back to first team inside occluders; body setup is defaults, wheel anchors/camera are copied constants. A single angle's result is not all-angle visibility, lighting, or foreshortening evidence.

## Helmet and trace authoring contracts

`tools/car/helmet-sheet.mjs:25-223` evaluates runtime Helmets/Teams directly, derives roster labels, supports multiple front/side/rear/left/quarter/top views, number filter, min80px cell, plain or mesh paint mode. Marches real SHAPE/pointAt ovoid/chin shell, numerical normal, fixed directional+ambient light, glass highlight. Optional meshSkin reproduces runtime adaptive subdivisions and centroid paint, while default samples continuous painter. Sharp composites labeled PNG to `scratch/renders/<out>` (absolute/parent out can escape this default). Invalid views are filtered rather than rejected. It previews isolated paint/shell, not halo obstruction or circuit lighting.

`tools/car/helmet-trace.mjs:25-496` is fixed-reference authoring, not a general current-roster extractor. GRID names a 20-cell 2025 sheet, ignores DOO/TSU entries with null current numbers, defaults `scratch/refs/f1-2025-helmets.webp`. Flood-fills background from corners, segments blobs with size/aspect cutoffs, orders row-wise, trims narrow shadows. Projects real shell at side-on azπ/2/el4°, samples only face dot>=.55 using neighborhood quantized mode, mirrors/fills missing ring cells and normalizes slowly-varying value channel. Always writes `scratch/refs/helmet-maps.json` before optional report/score/fit/emit/palette. A count mismatch warns and still pairs min(count,20), so registration/order errors can mislabel. Fit is bounded coordinate descent of zone t/t0/t1 (steps .06/.03/.015, displacement<=.13) with mirrored parameters tied. Emit prints reconstructed zone helper text; does not write helmets.js. Author comment explicitly documents that improved objective produced worse pale bands; treat fit as hypothesis. `--palette` still runs sheet mapping first and therefore requires sheet input too. Header's `--check` is not read by implementation; there is no generic help guard or unknown-flag validator.

`tools/car/trace-car.mjs:36-268` self-serves isolated viewer, shoots visible and hideCar stage after frame-counter +6 (no shared generation/presentation helper), reads soft/view canvas. Difference mask RGB sum>10, neighbor despeckle, Moore loops, RDP simplify, Sobel interior edges, cumulative luminance tone bands, fit to target box. Writes JSON camera/box/source/coverage/outline/tone/detail; default `artifacts/car-trace/trace.json`. `--png` actually writes **trace.svg**, no PNG encoder. Zero difference exits 1; no semantic validation. User paths resolve against repo root without output restriction. Browser/server finally close; no runtime source write.

`tools/car/trace-logo.mjs:40-490` reads historical `assets/logos/<id>.png` via git show pinned `0d040af` unless --rev, decodePNG; deterministic opacity-filtered k-means up to configured layers, cumulative back-to-front masks, Moore loops/RDP/minarea and normalized fit box. SOURCES defines inks/roles/base/islands/drop and excludes Haas/Audi/Mercedes from default traced output for source-quality reasons. `groupLoops` groups overlapping interiors at 200px, not bbox overlap; sorted leftmost x; `toPathData` emits M/L/Z. CLI prints JSON `{roles,d}`, --parts diagnostics, optional source/trace PNG, --write replaces whole runtime CrestPaths object for requested/default list. A subset `--write` therefore omits other teams. `--rev` changes input but emitted provenance prose still interpolates DEFAULT_REV, a source-evidenced metadata limit. Generated path consumer is livery renderer, not this CLI at runtime.

`tools/garage/author-crew-motion.py:1-93` requires Blender bpy. Clears scene, creates editable armature + two-bone IK foot/hand controls and bone-parented proxy meshes. 24fps frames1..49, 1.35m smooth retreat, four staggered planted steps, periodic asymmetric hand signal. Blender XYZ equals game X,-Z,Y; sampled output is game footLY/LZ/RY/RZ/reach/handY/bob in meters, 25 rows at two-frame stride rounded six places. Checks proxy-center error<.001m and hand-target distance<.61m. Writes `garage-guide-actions.blend` and `crew-motion.json` in required output-dir with validation/source SHA/version/fps/channels/license metadata. Optional --write-runtime marker replacement puts KEYS and source hash into `js/garage/crew-motion.js`; runtime `GarageCrewMotion.sample` linearly interpolates seven channels, `walking` maps traveled distance to repeating authored gait. `tests/unit/garage-crew.test.mjs:295-298` pins embedded hash to author source. Script sets no Blender version check although runtime-block text says Blender4.3. It creates keyframed objects and channels but does not export a skinned GLB or second game mesh.
