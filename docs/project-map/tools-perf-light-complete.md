## Ownership and data flow

- Browser-owning CLIs generally use `tools/lib/harness.mjs` for static server, Chromium and shutdown: profile, garage, mesh, matrix, WGSL capture, lighting A/B, tuner sweep and slider live. Their measurements are heterogeneous: CPU spans, submitted geometry counts, shader text, JPEG/PNG deltas and callback cadence are not interchangeable GPU performance evidence.
- `boost-press-census.mjs` and `idle-pipeline-census.mjs` receive a test-owned page and real-input callback. They wrap three's pipeline constructor in that page and leave instrumentation/rAF alive until its owner disposes it. `runtime-memory.mjs` similarly receives an existing owner-held CDP session and does not close it.
- `diagnostics.mjs` builds bounded child-command plans, reserves a fresh output directory and supervises the full detached producer tree. The MCP wrapper routes browser jobs through the shared job/lock machinery; offline queries only read reports. This is separate from the one-shot research CLIs.
- VM censuses own Node sandbox games; allocation additionally owns an isolated GC-enabled child process. They count the simulation/backend contract, not real renderer caches or GPU residency.
- Device Farm local orchestration owns metered AWS remote sessions and Appium sessions; its automated mode packages the dependency-free host script for an AWS Mac. Local parsers and pure method helpers never contact AWS.
- Lighting tools have three distinct models: source-replacement A/B (`ab-lighting`), paired live A→B→A′ pixel sweep (`lighting-tuner-sweep`), and heuristic source classification plus recipe-based live ramps (`slider-effect`). Preset validation is a separate author-time contract shared with bake/merge-proposal scripts.

## Per-file contracts: profiler and diagnostics

**`tools/perf/lib.mjs`** ([source](../../tools/perf/lib.mjs#L5), lines 5–107). Pure exports: median/spread, aggregate, MIN_REPEATS, verdict/diff, table formatters, profileScenario/signature/comparability, supportsCaptureKey and intervalStats. Aggregation takes each span's median statistic across repeats, sums sample counts and retains p50/p95 spreads. Verdict requires at least three repeats per arm, treats absolute deltas within the larger spread as noise, and leaves `raf` informational. Scenario equality requires version/workload/warmup, track/frames, viewport/DPR, capture and observed backend/API/device/browser; unknown metadata blocks a verdict. Capture support is substring detection in source, not proof of a working renderer. `formatDiff` prints p50 verdict while rows also contain verdict95. Used by profile/query and profile unit tests; no I/O/browser ownership.
